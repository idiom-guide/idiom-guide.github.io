create

create · created · created行動與變化原書第 86 條

核心意象「無中生有」：創造、創作，延伸為造成（局面、情緒）與創造（就業機會）。

義項與同義詞 2 個義項

左欄每個意思都能用 create 來說；反過來，不想一再重複 create 時，右欄的同義詞都能替換。點左側圖示，可以看到還有哪些動詞能表達同一個意思。

  1. 創造・造成・設計cause to exist
    makeproducedesigninventbuildbring aboutcauseengenderlead to

    The policy has created a lot of uncertainty.

    這項政策造成很大的不確定性。

  2. 創造（職位）；冊封appoint
    generatemakeappoint

    The project will create 500 jobs.

    這項計畫將創造五百個就業機會。

慣用語 2

  • create a scene大吵大鬧・當眾出醜
  • create an uproar引起軒然大波

口譯員提醒

「創造就業」是 create jobs；「營造氛圍」可以說 create an atmosphere。中文的「造成困擾」也常譯成 create problems。
