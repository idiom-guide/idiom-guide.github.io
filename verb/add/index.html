add

add · added · added行動與變化原書第 4 條

核心意象「再加上去」：數字相加、內容增補；說話時「補充一句」也是 add。

義項與同義詞 3 個義項

左欄每個意思都能用 add 來說；反過來，不想一再重複 add 時，右欄的同義詞都能替換。點左側圖示，可以看到還有哪些動詞能表達同一個意思。

  1. 加總・相加count up
    totalreckonsum upcomputeadd up

    If you add the shipping fee, it comes to NT$1,200.

    加上運費，總共新臺幣一千二百元。

  2. 增加・附加include
    includeattachsupplementincreaseannexamplifyaugmentextend

    We've added two new routes this year.

    我們今年新增了兩條航線。

  3. 補充說continue to speak
    go oncarry oninterject

    "And it has to be done by Friday," she added.

    她補了一句：「而且週五前要完成。」

片語動詞 5

  • add in加進去
    include
  • add on附加・加蓋

    The hotel adds on a service charge.

    飯店會另加服務費。

    includeattach
  • add to增添・加劇

    The rain only added to the confusion.

    下雨讓場面更混亂。

    increasecontribute to
  • add up加總；說得通；積少成多

    His story just doesn't add up.

    他的說法根本兜不攏。

    count upmake sensehold waterbe consistentaccumulate
  • add up to總計達；等於是
    amount tosignifyconstitutemean

慣用語 3

  • added to this/that除此之外・再者
  • add insult to injury傷口上撒鹽
  • add fuel to the fire火上加油

本站成語

口譯員提醒

「我補充一點」說 If I may add… 或 I'd just like to add that…，比 supplement 自然得多。
