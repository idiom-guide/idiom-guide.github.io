build

build · built · built行動與變化原書第 55 條

核心意象「一層層蓋起來」：建造房屋，延伸為建立（關係、事業）、累積，以及（緊張）逐漸升高。

義項與同義詞 2 個義項

左欄每個意思都能用 build 來說；反過來，不想一再重複 build 時，右欄的同義詞都能替換。點左側圖示，可以看到還有哪些動詞能表達同一個意思。

  1. 建造・建立makevt.
    constructput uperectcreateset upfounddevelopform

    It takes years to build trust.

    建立信任需要好幾年。

  2. 逐漸升高・累積increasevi.
    accumulateescalaterisemount

    Pressure on the government is building.

    政府面臨的壓力越來越大。

片語動詞 3

  • build in/into內建・納入

    Flexibility is built into the contract.

    合約中已納入彈性條款。

    incorporateintegrate
  • build on以…為基礎

    We want to build on last year's success.

    我們希望在去年的成功基礎上更上層樓。

    developcapitalise on
  • build up建立；增強；累積；捧高
    developforgefosterpromoteaccumulatepile upencourage

慣用語 4

  • build bridges搭起溝通橋梁
  • build castles in the sky空中樓閣
  • build on sand根基不穩
  • of medium build中等身材

口譯員提醒

「建立互信」是 build trust，「建立共識」是 build consensus，「能力建構」是 capacity building。「在…基礎上」說 build on，國際會議發言很常用。
