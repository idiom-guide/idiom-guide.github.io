start

start · started · started行動與變化原書第 60 條

核心意象「開始」：開始做某事、發動（機器）、創辦（事業），也有「嚇一跳」的意思。

義項與同義詞 4 個義項

左欄每個意思都能用 start 來說；反過來，不想一再重複 start 時，右欄的同義詞都能替換。點左側圖示，可以看到還有哪些動詞能表達同一個意思。

  1. 開始・創辦beginvt.
    kick offcommenceembark oninitiateundertakeget under wayset upfoundlaunch

    Let's start the meeting.

    我們開始開會吧。

  2. 發動（引擎、機器）activatevt.
    switch onturn onstart up

    The car won't start.

    車子發不動。

  3. 開始・上工beginvi.
    begincommenceget going

    Can you start on Monday?

    你星期一可以開始上班嗎？

  4. 嚇一跳jumpvi.
    jerktwitchflinchwincerecoil

片語動詞 5

  • start out起步；出發

    She started out as a court interpreter.

    她一開始是當法庭口譯。

    begin one's careerset out
  • start up創辦；啟動
    set upfoundlaunch
  • start off以…開始

    Let me start off by welcoming our guests from Japan.

    首先，我要歡迎來自日本的貴賓。

    beginkick off
  • start sb off帶（某人）入門；引人發笑
    get sb going
  • start over重新開始
    restartbegin again

慣用語 5

  • start afresh重新開始
  • to start with首先；起初
  • a fresh start新的開始
  • a head start先發優勢
  • in fits and starts斷斷續續
