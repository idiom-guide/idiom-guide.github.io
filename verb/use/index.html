use

use · used · used取得與給予原書第 18 條

核心意象「拿來用」：使用工具與方法、消耗資源，也指利用他人。

義項與同義詞 3 個義項

左欄每個意思都能用 use 來說；反過來，不想一再重複 use 時，右欄的同義詞都能替換。點左側圖示，可以看到還有哪些動詞能表達同一個意思。

  1. 使用・運用utilize
    employmake use ofapplyoperateexercisepractiseresort toexert

    Can I use your charger?

    可以借用你的充電器嗎？

  2. 消耗・用掉consume
    go throughget throughexhaustspendrun throughdepletewastesquander

    The new system uses far less electricity.

    新系統用電少很多。

  3. 利用（他人）take advantage of
    take advantage ofexploitmanipulateabusemilkprofit fromimpose on

    I felt she was just using me.

    我覺得她只是在利用我。

片語動詞 1

  • use up用完・耗盡
    consumeexhaustfinish

慣用語 10

  • in use使用中・通行
  • it's no use沒用・徒勞
  • no use crying over spilt milk覆水難收・後悔無益
  • make use of利用
  • out of use停用・壞了
  • put sth to good use善加利用
  • use every trick in the book用盡各種手段
  • use one's head動動腦
  • could use sth很需要…
  • use it or lose it不用就會生疏・不用就失效

本站成語

公器私用use public resources for private ends

口譯員提醒

「我很需要幫忙」口語可說 I could use some help.；「學以致用」可譯 put what you've learned to good use。utilize 多見於正式書面，口說用 use 即可。
