run

run · ran · run移動與位置★ 先學原書第 13 條

核心意象「快速、持續地移動」：跑、逃，延伸為（車輛）行駛、（機器）運轉、（液體）流動、（道路）延伸、（活動）持續，還有經營與參選。

義項與同義詞 12 個義項

左欄每個意思都能用 run 來說；反過來，不想一再重複 run 時，右欄的同義詞都能替換。點左側圖示，可以看到還有哪些動詞能表達同一個意思。

  1. 跑・奔movevi.
    racesprintrushdashdartspeedhastencharge

    She ran to catch the bus.

    她跑去趕公車。

  2. 逃跑fleevi.
    escapebolttake flightmake off

    When the police arrived, the suspects ran.

    警察一到，嫌犯就逃了。

  3. （車輛）行駛；（機器）運轉govi.
    travelshuttleply a routeworkgooperatefunctiontick over

    The shuttle bus runs every twenty minutes.

    接駁車每二十分鐘一班。

  4. 流・淌flowvi.
    streampourgushspurtcascadeflooddripmelt

    Tears were running down her face.

    她淚流滿面。

  5. 延伸・持續extendvi.
    stretchgoreachleadcontinuerangetrailspread

    The exhibition runs until the end of March.

    展覽展到三月底。

  6. （顏色）暈開・掉色spreadvi.
    be diffusedlose colourmixbleedcirculate
  7. 參選・參賽competevi.
    competeparticipateentercontendstand forcontest

    She is running for mayor.

    她正在競選市長。

  8. 經營・主持・執行managevt.
    be in charge ofadministerheadoverseesupervisecarry outconductperformmaintainown

    He runs a small translation agency.

    他經營一家小型翻譯社。

  9. 刊登・播出showvt.
    printpublishfeaturereleaseissuebroadcast

    Several papers ran the story on the front page.

    好幾家報紙把這則新聞登在頭版。

  10. 載送；走私conveyvt.
    give someone a lifttakedrivesmuggletraffic indeal in

    I'll run you to the station.

    我開車送你去車站。

  11. （手、梳子）滑過movevt.
    passskimslide
  12. 拉（線、管子）extendvt.
    stretchlay

片語動詞 11

  • run after追趕
    followchasepursue
  • run away逃走・離家出走
    escapeboltflee
  • run down貶低；耗盡；撞倒；累垮

    The batteries have run down.

    電池沒電了。

    criticisebelittledenigratedepleteknock overexhaust
  • run in磨合（新車、新設備）
    break in
  • run into巧遇；遇上（困難）

    We ran into problems with the visa.

    bump intochance uponfaceexperience
  • run off逃走；私奔；捲款潛逃；印出
    take flightelopeembezzleprintduplicate
  • run on以…為燃料
    burnuse
  • run out用完；到期

    We're running out of time.

    Let's run through the agenda before the guests arrive.

    客人到之前，我們先把議程過一遍。

    checkexaminego throughrehearsepractise

    accumulateraiserun up

口譯員提醒

「經營公司」「主持專案」用 run 就夠：run a company、run a project，不一定要 manage 或 operate。「時間快不夠了」是 We're running out of time.，「會議超時」是 The meeting ran over.
