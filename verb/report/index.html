report

report · reported · reported言語與溝通原書第 91 條

核心意象「回報」：報告、報導、通報，也指報到與（職務上）向某人負責。

義項與同義詞 3 個義項

左欄每個意思都能用 report 來說；反過來，不想一再重複 report 時，右欄的同義詞都能替換。點左側圖示，可以看到還有哪些動詞能表達同一個意思。

  1. 報到present oneself
    check inturn up

    Please report to the front desk on arrival.

    抵達時請到櫃檯報到。

  2. 向…負責・隸屬answer to
    be accountable toanswer to

    The task force reports directly to the premier.

    該工作小組直接向行政院長負責。

  3. 報告・報導・通報relatevt.
    declaretellinformdescribediscloserecordnote

    The incident was reported to the police.

    這起事件已向警方報案。

慣用語 2

  • be reported to據報導
  • report back回報結果

口譯員提醒

新聞的「據報導」是 reportedly 或 It is reported that…；職場的「直屬上司」是 the person you report to。
