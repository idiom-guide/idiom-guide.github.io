learn

learn · learned/learnt · learned/learnt心智與感知原書第 78 條

核心意象「學會、得知」：學習技能、背誦，也指聽說、獲悉某件事。

義項與同義詞 3 個義項

左欄每個意思都能用 learn 來說；反過來，不想一再重複 learn 時，右欄的同義詞都能替換。點左側圖示，可以看到還有哪些動詞能表達同一個意思。

  1. 學・學會mastervt.
    acquirepick upbe taughtgain knowledge ofmaster

    It takes years to learn simultaneous interpreting.

    學會同步口譯要好幾年。

  2. 背・記住memorizevt.
    commit to memorylearn by heart

    I learned the speech by heart.

    我把講稿背下來了。

  3. 得知・獲悉discovervt.
    find outcome to knowbecome awarehearbe informed of

    We learned that the flight had been cancelled.

    我們得知班機取消了。

慣用語 6

  • learn a thing or two學到一些東西
  • learn to live with學著接受
  • learn one's lesson學到教訓
  • you live and learn活到老學到老
  • learn by heart背熟
  • learn the hard way吃過苦頭才學乖

口譯員提醒

「據悉」「獲悉」在新聞裡常說 It has been learned that… 或 We have learned that…；「從錯誤中學習」是 learn from mistakes。
