pull

pull · pulled · pulled移動與位置原書第 39 條

核心意象「往自己這邊拉」：拖、拔，延伸為吸引人潮、拉傷肌肉，以及開車靠邊、撤出、撐過難關。

義項與同義詞 5 個義項

左欄每個意思都能用 pull 來說；反過來，不想一再重複 pull 時，右欄的同義詞都能替換。點左側圖示，可以看到還有哪些動詞能表達同一個意思。

  1. 拉・拖dragvt.
    drawhaultrailtowtugjerkyankwrench

    Pull the door, don't push it.

    門要用拉的，不是推的。

  2. 拔出・抽出extractvt.
    pickremovetake outpluckuprootdraw out
  3. 吸引（人潮）attractvt.
    attractdrawbring inlurepull in

    The festival pulls huge crowds every year.

    這個節慶每年都吸引大批人潮。

  4. 拉傷strainvt.
    straintearsprainwrench

    He pulled a muscle during the warm-up.

    他熱身時拉傷了肌肉。

  5. 用力拉dragvi.
    tugheave

口譯員提醒

「退出協定」「撤資」說 pull out of…，新聞口譯很常用；「動用關係」是 pull strings；「同心協力」是 pull together。
