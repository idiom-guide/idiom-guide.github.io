use

use · used · usedGetting & givingNo. 18 in the original

Core imagePutting something to work: using tools and methods, consuming resources, and using other people.

Meanings and synonyms 3 meanings

Every meaning on the left can be expressed with use; when you would rather not repeat use, the synonyms on the right can replace it. Select an icon to see which other verbs share that meaning.

  1. 使用・運用utilize
    employmake use ofapplyoperateexercisepractiseresort toexert

    Can I use your charger?

    可以借用你的充電器嗎？

  2. 消耗・用掉consume
    go throughget throughexhaustspendrun throughdepletewastesquander

    The new system uses far less electricity.

    新系統用電少很多。

  3. 利用（他人）take advantage of
    take advantage ofexploitmanipulateabusemilkprofit fromimpose on

    I felt she was just using me.

    我覺得她只是在利用我。

Chinese idioms on this site

公器私用use public resources for private ends

Interpreting tip

"I could use some help" is a casual way to say you need help. Utilize belongs to formal writing; in speech, use is enough.
