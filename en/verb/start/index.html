start

start · started · startedDoing & changingNo. 60 in the original

Core imageBeginning: starting to do things, starting machines, starting businesses, and starting in surprise.

Meanings and synonyms 4 meanings

Every meaning on the left can be expressed with start; when you would rather not repeat start, the synonyms on the right can replace it. Select an icon to see which other verbs share that meaning.

  1. 開始・創辦beginvt.
    kick offcommenceembark oninitiateundertakeget under wayset upfoundlaunch

    Let's start the meeting.

    我們開始開會吧。

  2. 發動（引擎、機器）activatevt.
    switch onturn onstart up

    The car won't start.

    車子發不動。

  3. 開始・上工beginvi.
    begincommenceget going

    Can you start on Monday?

    你星期一可以開始上班嗎？

  4. 嚇一跳jumpvi.
    jerktwitchflinchwincerecoil

Interpreting tip

To open a speech: "Let me start by…" or "To start with…", a change from "First of all". A new company is a startup.
