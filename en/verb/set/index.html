set

set · set · setMotion & position★ Start hereNo. 15 in the original

Core imagePutting firmly in place: setting things down, setting a time, setting rules, setting things in motion. The sun "sets" too.

Meanings and synonyms 6 meanings

Every meaning on the left can be expressed with set; when you would rather not repeat set, the synonyms on the right can replace it. Select an icon to see which other verbs share that meaning.

  1. 放置・安放placevt.
    putplacelaypositionpose

    She set the tray on the table.

    她把托盤放在桌上。

  2. 定下・安排arrangevt.
    settlefixscheduleestablishdetermineappointassignarrangepreparemake ready

    Let's set a date for the next meeting.

    我們訂一下下次開會的日期。

  3. 樹立・制定establishvt.
    imposespecifylay downdecreeordaincreate

    The new rules set a high standard for safety.

    新規定為安全訂下高標準。

  4. 使開始・使處於causevt.
    incitecause to beginmakestart

    Her remarks set everyone talking.

    她的話引起大家議論紛紛。

  5. 設定・調整activatevt.
    switch onturn onactivateprogrammeadjustsynchronize

    I've set my alarm for six.

    我把鬧鐘設在六點。

  6. （日月）落下；衰落declinevi.
    go downsinkdipdeclinedisappearvanishsubsidewane

Interpreting tip

For founding a body, team or fund, set up is the natural choice; establish is for formal writing. Set a goal, set a deadline.
