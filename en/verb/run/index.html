run

run · ran · runMotion & position★ Start hereNo. 13 in the original

Core imageFast, continuous movement: running and fleeing, then vehicles running, machines running, liquids running, roads running and events running on; also running a business and running for office.

Meanings and synonyms 12 meanings

Every meaning on the left can be expressed with run; when you would rather not repeat run, the synonyms on the right can replace it. Select an icon to see which other verbs share that meaning.

  1. 跑・奔movevi.

  2. 逃跑fleevi.

Interpreting tip

Run is enough for managing things: run a company, run a project. "We're running out of time" and "The meeting ran over" are everyday meeting language.
