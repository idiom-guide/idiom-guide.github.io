write

write · wrote · writtenSpeakingNo. 64 in the original

Core imagePutting words on paper: writing letters and texts, and an author writing or arguing something.

Meanings and synonyms 5 meanings

Every meaning on the left can be expressed with write; when you would rather not repeat write, the synonyms on the right can replace it. Select an icon to see which other verbs share that meaning.

  1. 寫（字）form lettersvt.
    spellnotescribblescrawlput down

    Please write your name in block capitals.

    請以正楷大寫填寫姓名。

  2. 撰寫・開立createvt.
    composedraftdraw uppreparesign

    She's writing a book on court interpreting.

    她正在寫一本關於法庭口譯的書。

  3. 寫信communicatevt.
    correspondcommunicate

    I'm writing to ask about the training course.

    來信想詢問培訓課程的事。

  4. 會寫字literacyvi.
    be literate
  5. （在文中）寫道・主張statevi.
    claimpoint outdeclarestate

    In her latest paper she writes that the policy has failed.

    她在最新論文中寫道，這項政策已經失敗。

Phrasal verbs 5

  • write down寫下；（資產）減記
    note downrecorddepreciate
  • write in投書；加寫
    write a letteradd
  • write off視為失敗；打銷（資產、債務）；撞爛

    The bank wrote off the bad loans.

    銀行打銷了呆帳。

    dismissgive up oncancelwreck
  • write out完整寫出；列出
    spell outset out
  • write up撰寫成文

    Could you write up the minutes?

    可以把會議紀錄整理成文嗎？

    write a report on

Idioms 4

  • written all over sb's face全寫在臉上
  • not much to write home about平平無奇
  • have sth written all over it一看就是…的手筆
  • a write-off報廢・徹底失敗

Related glossary terms

Write-off沖銷Accounting & Financial Reporting

Interpreting tip

Formal letters open with "I'm writing to…". In accounts, write off and write down are financial terms. Write up the minutes after a meeting.
