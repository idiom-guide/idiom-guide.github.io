十・學習與治學

學無止境

英文怎麼說

  • there is no end to learning

意思

學習沒有盡頭。正・一般

其他英文說法

  • never stop learning終身學習
  • you learn something new every day每天都學到新東西

例句

學無止境，永遠有新東西可學。

There is no end to learning.

用法

多用於勉勵、自謙。

近義

  • 📗開卷有益reading is always rewarding

    讀書總有好處。

    開卷有益，不管讀什麼書都有收穫。

  • 🔁溫故知新review the old to learn the new

    溫習舊知識，得到新體會。

    溫故知新是學習新知最好的方法。

反義

  • 🍴淺嘗輒止dabble; try only a little and stop

    稍微嘗試就停止，不深入。

    他對什麼都淺嘗輒止，沒有一樣學到底。
